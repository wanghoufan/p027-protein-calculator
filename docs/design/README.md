## 规则

1. **SPEC 行为优先**：行为、数据、验收以 SPEC/PLAN/TASKS 文字规范为准，本目录参考图仅约束视觉（颜色、圆角、层级、间距）。
2. **iPhone 系统外框不可照搬到 Android**：参考图中的 iPhone 外框、状态栏、底部 Home Indicator 仅用于视觉表达，Android 必须按系统 Safe Area / System Bars 适配，不画假的 iOS chrome。
3. 参考图中的“营养知识”入口、底部 Tab、无行为齿轮、额外推荐区间不属于 V1，禁止实现。
4. 方案 B 视觉：米白背景、健康绿主色、圆角白卡、轻阴影。
